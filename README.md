# Gumbo Sounds

Free instruments for **Gumbo**, EON Studios' SFZ instrument player for REAPER, installed through ReaPack: the whole
of **VSCO 2 Community Edition** by Versilian Studios, 75 instruments at full quality, every recording kept as it was
made (lossless FLAC).

## Gumbo starter sounds

Twelve instruments, about 230 MB: upright piano, violin and cello sections, plucked violins, French horn, trumpet,
flute, clarinet, harp, organ, marimba and timpani.

## Gumbo VSCO 2 CE orchestra

The other sixty-three, about 530 MB:

- **Strings**: solo violin; violin, viola, cello and double bass sections, each with sustain, vibrato, tremolo,
  pizzicato and spiccato, and key-switched versions that change playing style from a key.
- **Woodwinds**: flute, piccolo, oboe, clarinet and bassoon, sustained and staccato.
- **Brass**: French horn (open and muted), trumpet (open, straight mute and harmon mute), trombone and tuba.
- **Keys and percussion**: a second upright piano, loud and quiet pipe organ with pedals, glockenspiel, xylophone,
  tubular bells, timpani rolls and a General MIDI style percussion kit.

## Install

You need Gumbo first ([its own repository](https://github.com/mequaz-sudo/Gumbo)).

1. **Extensions > ReaPack > Import repositories**, paste this address and click OK:

   ```
   https://raw.githubusercontent.com/mequaz-sudo/Gumbo-Sounds/main/index.xml
   ```

2. **Extensions > ReaPack > Browse packages**, type **Gumbo**, install **Gumbo starter sounds** and **Gumbo VSCO 2
   CE orchestra** (either or both), then click **Apply**. The orchestra is about 530 MB and 1,900 files, so the
   download takes a while.
3. Close and reopen Gumbo's window: the new instruments are in its browser.

If you installed **Gumbo starter sounds** or the orchestra from Gumbo's own repository before November 2026, you
already have them: ReaPack lists that copy as obsolete and it keeps working. To take updates from here, uninstall it
in ReaPack first, then install it from this repository.
